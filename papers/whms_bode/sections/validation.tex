\section{What a replacement validation would need to establish}
\label{sec:validation}

The paired analysis shows why specifying the target changes an assessment:
the same intervals can have different inclusion rates against a sampled
reference and the generating-pool parameter. A clinical simulator likewise
needs to distinguish a requested population treatment effect, a latent
finite-cohort effect and an observed-data contrast. Coverage must use the
target for which the interval was designed.

The earlier recovery curve admits a simpler explanation. The oracle estimate
applies Equation~\ref{eq:kitagawa} to the sampled fractions and means, exactly
reproducing their empirical decomposition. This arithmetic identity explains
the comparison without evaluating its uncertainty. For example, the same
sample mean has about 95\% or 36\% coverage when only its interval width changes
(Appendix~\ref{app:matrix}). Established trial-estimator relationships and
learned-generator checks are collected there as supporting examples.

Assess the whole decision rule using the interval that would actually
be reported. Record bias and error against the chosen target, null rejection,
detection at the specified effect, and abstention frequency. Report both
conditional interval performance among returned answers and how often a valid
answer is returned. A successful effect-detection rate can accompany excessive
null rejection, so the former alone cannot validate an interval. The null target here is 5\% because the intervals are nominally 95\%.

Separate selecting a rule from assessing it. If a scalar threshold is
intended to guarantee performance above that threshold, qualification must
address the evaluated upper range rather than only its first passing point.
Reserve independent simulation draws for the final assessment, report rate
uncertainty and the tested range, and distinguish this from transfer to new
patients or cohorts. Increasing resamples from an empirical pool improves
conditional numerical precision; it does not broaden that pool's biological
support. For an external-control application, the additional question is
comparability across data sources, which requires direct study-level validation
such as the held-out comparisons of \citet{ventz2019}. Evaluating transfer to
patient populations requires that additional evidence.

\subsection{A synthetic external-control example: validating the wrong population}
\label{sec:eca}

A separate constructed experiment makes target-population mismatch consequential.
A fixed synthetic registry supplies a single-arm trial and three external
controls per enrolled patient. Enrolment favors heavily pretreated strata;
induced benefits vary by stratum and latent individual responsiveness.
The intended target is the mean individual treatment effect among enrolled
records. We compare stratum contrasts standardized to the enrolled population
with the same contrasts averaged over the pooled trial-plus-control file.
The latter estimates a different population effect; it is defective only
relative to the stated enrolled-population target. Appendix~\ref{app:eca}
specifies the design and controls.

At 1{,}600 enrolled patients, pooled standardization has a median estimate of
1.890 outcome units while the enrolled records' median true effect is 1.003.
These medians fall on opposite sides of the prespecified illustrative threshold
of 1.5; this is not an estimated probability of a wrong decision.
Against the observed pooled contrast, the pooled estimator has zero error by
construction, while enrolled standardization appears inaccurate
(Table~\ref{tab:eca}). Using the enrolled potential-outcome reference reverses
that ranking. Merely using potential outcomes is insufficient: averaging them
over the pooled population still favors the estimator of the wrong target.
The target must specify both the effect and the population over which it is
averaged.

Two controls limit the interpretation. At zero case-mix shift, pooled
standardization still reproduces its observed-data reference but its bias
against the enrolled effect is only $-0.002$ units. Equality therefore does
not establish that an estimate is wrong. Under the full shift, pooled
weighting balances the measured strata between arms to numerical precision
while their weighted distribution differs from the enrolled distribution
(maximum standardized difference 0.964). Between-arm balance does not establish
target-population alignment. This constructed, uncensored outcome experiment
demonstrates a possible validation failure; it supplies no evidence of its
prevalence or of performance in an actual clinical trial.
