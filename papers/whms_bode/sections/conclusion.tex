The synthetic external-control example shows how a validation reference can
favor an estimator of the wrong population effect. The audited 50-cell rule fails joint interval evaluation despite reassuring
point-estimate recovery. A larger simulation budget distinguishes three
coverage failures from one passing condition, while excess null rejection
and insufficient detection occur in all four. Welch intervals improve coverage
but do not repair the reporting boundary. In the higher-precision pooled-draw study, the detection trough becomes
interpretable alongside the changing false-positive rate.

A reporting threshold must be assessed with its actual interval, explicit
target and null and alternative operating characteristics. The target must name the population over which effects are averaged, and
qualification must address the range over which the rule will report.
Recovery alone supplies neither guarantee.
