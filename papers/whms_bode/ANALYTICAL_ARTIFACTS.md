# Local analytical sources outside the submission

`main.tex` and its recursive `\input` graph define the paper. `source.zip`
contains that graph, the cited figure assets, and supporting aggregate summaries.
It excludes the following local analysis files. They are retained because they
record earlier analyses or are generated/checked by repository scripts; their
presence does not mean they are compiled into the paper.

| Local source in `sections/` | Purpose and maintenance |
| --- | --- |
| `refdesign.tex` | Extended estimator, interval, censoring and learned-generator analysis; numerical claims checked by `test_results.py`. Its labels have the `analysis:` prefix so they do not collide with the submission's labels. |
| `learned_table.tex` | Extended learned-estimator table, regenerated by `make_tables.py`; all 30 numerical cells checked against pinned results. |
| `matrix_table.tex` | Historical estimator/reference identity matrix. |
| `fixed_pool_table.tex` | Earlier 200-replicate paired target diagnostic; generated by `make_fixed_pool_tables.py`. The paper uses the later 5,000-replicate table. |
| `low_count_table.tex` | Earlier low-count diagnostic, generated by `make_diagnostic_table.py`. |
| `reversal_table.tex` | Descriptive crossings in the 200-replicate grid, generated by `make_fixed_pool_tables.py`; these are not evidence of genuine local non-monotonicity. |

`supporting_check.tex` is compiled. It contains the concise reference-dependence
and learned-generator checks. The full interval-width example is only in the
local extended analysis; the unreferenced paragraph label was removed there.
