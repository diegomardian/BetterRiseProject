\paragraph{No biological or clinical claim is made, and the controls forbid
one.} Our instance is differentiation-marker loss in colorectal cancer, and we
report \emph{no} finding about the biology. The pre-registered control panel
names genes expected to move compositionally, genes expected to move
intrinsically, and one chosen because disease \emph{retains} it, which should
leave both arms alone. \iffull
The falsification rule was written into the configuration
file in week 0, before any analysis code existed --- \emph{if tiers A, B and D
all return the same answer, the estimator is broken and no biological claim may
be made} --- and it is mirrored by an exact-value assertion in the test suite, so
continuous integration fails if anyone edits it.
\else
The falsification rule --- if all three tiers return the same answer, no
biological claim may be made --- was written into the configuration file in week
0, before any analysis code existed, and is asserted in the test suite.

The pre-committed
consequence fired, and we take it: \emph{methods and validation only, no
biological claim}. A second cohort on a second platform reproduces the pattern,
which \textbf{confirms the artefact rather than the biology}. Cell fractions
govern the ratio between the arms, so this estimator was never going to separate
the tiers.

\paragraph{The misuse to guard against} is reading \notest{} as ``no effect''.
Here a confident null reads as ``the surviving cells are behaving normally'', a
mechanism claim with treatment implications\iffull{}
(Appendix~\ref{app:limitations})\fi.

\paragraph{Limitations.} Our calibration covers one gene, one axis and one
weighting, on two cohorts that return different cutpoints. The result shows
\emph{this} rule failing \emph{its own} criteria on both, not cell-count rules
failing in general. A draw-pool choice the
design document never makes moves the answer, the replicates are not
independent, and the absence-defined axis still tracks depth at 60\% of the
correlation its own prevalence permits (Appendix~\ref{app:limitations}). Both
cohorts are public, de-identified and previously published, and since single-cell
genotypes remain re-identifiable in principle, anything we release is derived
summaries and code rather than cell-level matrices.

\paragraph{Broader impact.} Any system reporting cell-type-resolved quantities
inherits Equation~\ref{eq:kitagawa}'s identifiability problem, and a system
always returning a number cannot separate a measured effect from an unaskable
question. Adding abstention costs little. \emph{Calibrating} abstention is the
step people skip.\iffull{} Publish the attempt, including when it yields no
cutpoint.\fi
